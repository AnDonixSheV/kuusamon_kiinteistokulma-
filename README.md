# Kuusamon Kiinteistökulma Oy

Verkkosivut kiinteistöhuolto- ja rakennusyritykselle Kuusamossa.

## Kuvaus

Moderni, responsiivinen yhden sivun verkkosivusto, joka esittelee yrityksen palvelut, referenssit ja yhteystiedot. Sivusto on optimoitu hakukoneille (SEO) ja toimii kaikilla laitteilla.

## Teknologiat

- HTML5 (semanttinen rakenne)
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Rakenne

```
├── index.html      # Pääsivu
├── style.css       # Tyylit
├── script.js       # Toiminnallisuus
└── images/         # Kuvat
    ├── logo.png
    ├── hero-bg.png
    ├── about.png
    └── ref-1..4.png
```

## Ominaisuudet

- Responsiivinen Mobile First -suunnittelu
- Kiinteä navigaatio scroll-efektillä
- Animoidut osiot (IntersectionObserver)
- Valokuva-galleria lightbox-näkymällä
- Yhteydenottolomake
- SEO-optimointi (meta-tagit, JSON-LD, semanttinen HTML)

## Käyttöönotto

Sivusto on staattinen ja voidaan julkaista millä tahansa web-palvelimella tai GitHub Pages -palvelussa.

### GitHub Pages

1. Luo uusi repository GitHubissa
2. Push koodi repositoryyn
3. Settings → Pages → Source: main branch
4. Sivusto on saatavilla osoitteessa `https://<username>.github.io/<repo-name>/`
